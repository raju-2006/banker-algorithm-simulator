Deadlock Avoidance and Resource Allocation

About Banker's Algorithm

Banker's Algorithm is a deadlock avoidance algorithm used by an operating system to decide whether allocating resources to processes will keep the system in a safe state.

This simulator accepts the Allocation Matrix, Maximum Matrix and resource information. It calculates the Need Matrix, Available Resources, Safe Sequence and also checks individual resource requests.

06 Resource Request Algorithm

A process may request additional resources while the system is running. The request can be granted only if:

Request[i] ≤ Need[i]
Request[i] ≤ Available

After temporarily granting the request, the system must still remain in a safe state.

07 Important Formulas

Need Matrix

Need[i][j] = Maximum[i][j] - Allocation[i][j]

Available Resources

Available[j] = Total[j] - Sum of all Allocation[i][j]

Safety Condition

Need[i] ≤ Work

If all processes can finish, the system is in a SAFE STATE. Otherwise, the system is in an UNSAFE STATE.

Resource Request

Request[i] ≤ Need[i]
Request[i] ≤ Available
Available = Available - Request
Allocation[i] = Allocation[i] + Request
Need[i] = Need[i] - Request
